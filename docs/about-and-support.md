# About & support

**Save 4Bucks** is a small offline utility for editing cash in GTA IV Complete Edition save files.

- **Repository:** [github.com/Metaheurist/4bucks](https://github.com/Metaheurist/4bucks)
- **Releases:** [github.com/Metaheurist/4bucks/releases](https://github.com/Metaheurist/4bucks/releases)
- **Issues:** use GitHub Issues on that repository

This project is not affiliated with Rockstar Games or Take-Two Interactive.
