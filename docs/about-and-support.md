# About & support

**Save 4Bucks** is a small offline utility for editing cash in GTA IV Complete Edition save files. The desktop UI is built with **Flet** (Flutter for Python).

- **Repository:** [github.com/Metaheurist/4bucks](https://github.com/Metaheurist/4bucks)
- **Releases:** [github.com/Metaheurist/4bucks/releases](https://github.com/Metaheurist/4bucks/releases) (`Save4Bucks-x64.exe` / `Save4Bucks-x86.exe`)
- **Issues:** use GitHub Issues on that repository
- **Docs hub:** see the [README](../README.md) documentation table

This project is not affiliated with Rockstar Games or Take-Two Interactive.
